# فواتيري — Fawateeri PWA

React 19 + TypeScript + Vite + Tailwind CSS v4 + IndexedDB.

## التشغيل محليًا

```bash
npm install
npm run dev
```

ثم افتح الرابط الذي يظهر (عادة `http://localhost:5173`).

للبناء للإنتاج (PWA قابلة للتثبيت):

```bash
npm run build
npm run preview
```

## البنية

```
src/
  lib/
    types.ts            أنواع البيانات (Invoice, Meta...) + دوال العملة
    db.ts                طبقة IndexedDB (متجرين: invoices و meta)
    AppDataContext.tsx    Context مركزي يربط الواجهة بـ IndexedDB
    useToast.tsx          نظام رسائل التأكيد (toast)
  components/
    PinLogin.tsx          تسجيل الدخول/تعيين رمز PIN
    BottomNav.tsx          شريط تنقّل سفلي
  pages/
    Dashboard.tsx          الرئيسية (كاردز إحصائيات)
    InvoiceForm.tsx        إضافة/تعديل فاتورة
    InvoicesList.tsx        قائمة الفواتير + بحث وفلترة
    InvoiceDetail.tsx      عرض وطباعة فاتورة
    Reports.tsx            تقارير + تتبع سعر البيع
    Settings.tsx            المظهر (ثيمان)، الشركة والتوقيع، العملات، نسخ احتياطي
```

## ما هو موجود الآن

- تسجيل دخول برمز PIN رقمي (تخزين محلي فقط، بدون تشفير حقيقي — لا تعتمد عليه لحماية بيانات حساسة).
- فواتير شراء/بيع بأصناف متعددة ومواصفات، محفوظة في IndexedDB.
- بحث وفلترة، تعديل وحذف الفواتير.
- تقارير: الأكثر توريدًا/بيعًا، ورسم بياني لتتبع سعر البيع.
- عملات قابلة للتخصيص (إضافة/حذف) وأسعار صرف لتوحيد التقارير.
- ثيمان (ذهبي/أزرق ليلي).
- توقيع الشركة (رفع صورة) يظهر في صفحة الفاتورة.
- طباعة الفاتورة عبر `window.print()` (يعمل بشكل طبيعي هنا لأن الصفحة تعمل في متصفح حقيقي، بخلاف نسخة الـ Artifact التجريبية).
- نسخ احتياطي JSON (تصدير/استيراد) عبر تنزيل ملف مباشر في المتصفح.
- إعداد PWA أساسي عبر `vite-plugin-pwa` (manifest + عامل خدمة)، مع أيقونات placeholder في `public/` يفضّل استبدالها بشعارك الفعلي.

## أفكار لإكمالها لاحقًا

- توقيع مرسوم باليد (canvas) — كانت موجودة في نسخة الـ Artifact التجريبية.
- تصدير PDF مباشر (`jspdf` + `html2canvas` كحزم npm عادية، أسهل بكثير هنا من البيئة المحمية للـ Artifact).
- مصادقة/تشفير أقوى لرمز الدخول.
- ربط تخزين سحابي لمزامنة البيانات بين أكثر من جهاز.
